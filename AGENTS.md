# Agent Instructions & Project Rules

## CRITICAL RULES FOR AI AGENTS (ANTIGRAVITY / GEMINI)

1. **NEVER RUN BUILD COMMANDS**:
   - **DO NOT** under any circumstances run `npm run build`, `yarn build`, `pnpm build`, or any other build script in this project.
   - Build commands are strictly managed outside the agent workflow or by the user.

2. **UI & Theme Guidance**:
   - Equalizer components must maintain custom dark theme styling.
   - Custom select dropdowns must match the app's dark theme palette (`#1c1c1e`, `#2c2c2e`, `#fa486f`).
